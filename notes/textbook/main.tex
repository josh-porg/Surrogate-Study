\chapter*{How to read this book}
This is a companion to the surrogate-modelling paper, not part of it. The paper's review says \emph{who} did
\emph{what}; this book says \emph{why it works}, \emph{what it is really computing}, and \emph{when it must fail}.
Every tool is built up from things you already know, and every named property is restated in words together with
the idea behind its proof. Probability is done with integrals throughout; a statistical table, when one appears, is
shown to be a precomputed integral.

Boxes: \textbf{Intuition} gives the informal reason a result is true; \textbf{Connection} links an idea to proper
orthogonal decomposition (POD), dynamic mode decomposition (DMD) or computational fluid dynamics (CFD);
\textbf{Pitfall} marks a place where practice goes wrong. Worked numbers come from scripts in this folder, so they
can be re-run.
