# SurrogatePaper

Paper project extending the surrogate-modelling study of the author's master's thesis
([Maters-Project-V3](https://github.com/josh-porg/Maters-Project-V3), read-only) using the thesis code
([COMPASS](https://github.com/josh-porg/COMPASS), read-only).

Part literature review, part global factorial study of surrogate pipelines: sampling → uncertainty/scout → learner →
multi-fidelity fusion → upscaling → optimizer, scored by true-function regret per unit simulation cost.
